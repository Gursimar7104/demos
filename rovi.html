Onboarding and data teardown for Rovi Health

Employers can already download hospital price files. Rovi’s pitch is that employees still book the expensive default. The public gap is between a published file and a booked, cheaper appointment.

Built by Gursimar Singh, Nov 2026

The Founding GTM Engineer role is meant to move Rovi past founder-led, referral-heavy sales. I used public federal rules and Rovi’s own site, not guessed claims data.

Rovi says it is an AI care concierge for employer health plans, that in-network prices for the same procedure can vary widely, and that it books members into higher-quality, lower-cost options. Source: rovi.health and the Founding GTM Engineer post.

What is already public

  • CMS requires hospitals to publish standard charges in a machine-readable file and to show shoppable services. Source: CMS Hospital Price Transparency.
  • Rovi’s job post uses an MRI example ($3,000 at a hospital vs $500 at an independent center). That example is Rovi’s, not a figure I independently verified on a hospital file this week, so I am not repeating it as a fact about a named facility.
  • The CMS rule gets the file into the open. It does not, by itself, text an employee, compare quality, and complete the booking, which is the product motion Rovi describes.

What this means for GTM

A first conversation with a benefits leader can start from a rule they already know (hospital price transparency) and then ask a narrower question: who on your team turns a published price into an appointment before the claim shows up months later? If the answer is “no one,” that is the opening the job post is trying to productize.

What I would build next

A one-zip walkthrough for a New York or New Jersey employer, using only files a hospital has already posted, that stops at “here is the cheaper option” and leaves the booking step marked as the part Rovi would own. I did not run that zip-level pass in this first page because I would want a specific employer’s plan network before putting numbers on a page.
