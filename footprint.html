Financial-crime data source map for Footprint

4 of the top 5 new data sources for Percy are ownership registries with public APIs, and FinCEN's BOI database now exempts US-formed companies

Built by Gursimar Singh, Nov 2026, on real public data

The role's biggest job is finding which data vendors are real and getting them signed. I mapped 21 sanctions/PEP, adverse media, ownership and device/IP sources from their own public pages and ranked them for Percy's KYB and EDD cases. Only 9 of the 21 put a price or free access on the page, so most of the list is a negotiation, not a checkout.

Percy score is my own heuristic, 0-8: real API (2) or file download (1); price or free access stated on the page (1); sanctions/PEP, adverse media or ownership data (2) vs device/IP (1, Footprint already ships fraud signals); primary government source (1). Minus 2 if Footprint's site already names it as a Percy integration, minus 1 if the vendor also sells competing compliance agents, minus 4 if the source is unusable. Coverage cells are quotes from each source's own page, fetched Nov 22, 2026.

How it works

  • Start from the four data types Percy's cases need (sanctions/PEP, adverse media, ownership registries, device/IP) and pick government, open and commercial sources for each.
  • Fetch each source's own pricing, docs or dataset page and quote what it actually says about coverage, API access and price. Anything not on the page is marked not published.
  • Score each source with the rubric above, subtract ones Footprint already integrates or that compete with Percy, and flag legitimacy issues like the FinCEN BOI exemption and the closed OFSI list.

What I'd improve next: Back-test the top 5 against 50 closed Percy cases to see which ones would have changed an outcome, get real quotes from the sales-led vendors (World-Check, Factiva, Middesk), and add US state registries since BOI no longer covers US-formed companies.
