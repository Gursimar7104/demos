Agent benchmark for Quantum Rise

Claude got 10 of 10 quarterly revenue figures right from Illinois 10-Qs. The free SEC API got the same 10 with no model.

Built by Gursimar Singh, Nov 2026

A small benchmark in the spirit of your post: before deploying an agent, test it, and check whether the job needs an LLM at all. I gave Claude raw income statement text from 10 Illinois public companies and asked for quarterly revenue in dollars. It handled the traps (Knowles Corporation reports in millions; Sprout Social, Inc., Tootsie Roll Industries Inc split revenue into lines before the total) and matched XBRL every time, but for tagged numbers like these the free XBRL API is the cheaper answer.

How it works

  • Pick Illinois companies from the SEC XBRL frames API with $12.5M to $250M in Q3 2026 revenue, skipping funds and REITs, and pull each 10-Q.
  • Send Claude only the income statement text and ask for the three-month revenue in whole dollars, with null if it is not there.
  • Plain code compares every answer to the XBRL value the company tagged. Same pipeline can score any model or prompt before a client sees it.

What I'd improve next: Point the same harness at numbers that are not tagged, like backlog, customer counts or guidance in the MD&A, where an LLM is actually needed and where it is more likely to miss.
