A sample target list for Olo · GTM Operations Analyst

Restaurant brands with a recent reason to talk

Built by Gursimar Singh, Nov 23, 2026, from public news and each brand's own ordering page

I'm Gursimar, a recent Rutgers IT grad. I saw Olo is hiring a GTM Operations Analyst to build restaurant target lists with signals like location count, franchise mix, current ordering provider, and leadership changes, so I made a small version of that list by hand.

Method: I used public news from roughly the last 90 days and then opened each brand's website or order page. If I could not confirm a fact, I left the cell blank instead of guessing. Brands whose order pages load Olo are in a second table, as possible upsell conversations, not new logos. This is a static snapshot, not a live Clay table.

These are the rows I would hand a mid-market or enterprise rep first. Online ordering is listed only when the public site made the provider clear.
